# training — ワークアウト記録 (Workout Tracker)

テキサスメソッド（4分割）向けのトレーニング記録アプリです。
公開URL: https://trsm01.github.io/training/

## 機能
- ホーム: Big3（ベンチプレス／スクワット／デッドリフト）の推定1RMと合計、主要種目の直近記録
- 予定・履歴: カレンダーで記録と予定を管理
- 記録: Day1〜Day4（Texas Method）のメニュー別にセット・重量・回数を記録し、推定1RMを自動表示
- AIコーチ: NSCA-CSCS観点の評価と次回メニュー提案のためのプロンプトを生成し、Gemini等に貼り付けて使えます。AIの回答（JSON）を取り込んで予定・記録に反映することもできます
- 設定: データのバックアップ（コピー）と復元

## データについて
- 記録はブラウザの localStorage に保存されます（サーバーには送信されません）。
- 保存先はブラウザごと・端末ごとです。機種変更やブラウザ変更の前に、「設定」からバックアップを取り、新しい環境で復元してください。
- 日付は端末のローカル時刻で判定します。
