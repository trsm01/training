# FORGE — トレーニングログ

トレーニング記録アプリ「FORGE」です。
公開URL: https://trsm01.github.io/training/

## 使い方
- ホーム: Big3（ベンチプレス／スクワット／デッドリフト）の推定1RMと合計、直近セッションの総ボリューム推移、最近の記録
- カレンダー: 月表示で記録のある日が色づきます（濃さ＝その日の総ボリューム）。日を選ぶと、その日の記録を種目・セットごとに振り返れます。編集・削除もここから
- 記録: 日付を選び、種目をプルダウンから選んで追加し、セットごとに重量・回数・メモを入力します。過去に記録した種目は前回のセット構成を引き継ぎます。プルダウンにない種目は「カスタム（自由入力）」で追加できます
- AIコーチ: 記録画面から、クラスターセット法の観点で評価と次回構成の提案を受けるためのプロンプトを生成し、Gemini等に貼り付けて使えます
- 設定: データのバックアップ（コピー／ファイル）と復元

## データについて
- 記録はブラウザの localStorage に保存されます（サーバーには送信されません）。保存先はブラウザごと・端末ごとです
- 旧アプリ（Workout Tracker）と同じ保存形式のため、これまでの記録はそのまま引き継がれます
- 機種変更やブラウザ変更の前に、「設定」からバックアップを取ってください
- 日付は端末のローカル時刻で判定します
